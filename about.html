소개

문혁재

AI 도구로 실무에서 실제로 쓰는 것을 만듭니다. 더큰내일교육센터 AI 취업역량강화 과정을 듣고 있고, 배운 것을 그때그때 도구로 만들어 써 보는 중입니다.

01

어떻게 만드는 편인가

규칙을 먼저 정하고, 지켰는지 확인할 방법까지 만든다

문서에 "이렇게 합시다"를 적어 두는 것만으로는 매번 흔들립니다. 그래서 규칙을 적을 때 그 규칙을 지켰는지 볼 방법을 같이 만듭니다. Slides-in-Html 의 자동 검사 일곱 가지가 그렇게 나왔습니다.

못 고친 것을 숨기지 않는다

완성했다고 말하는 것보다 어디까지 됐는지 정확히 말하는 쪽이 결국 더 쓸모 있었습니다. 프로젝트마다 "아직 못 고친 것"을 따로 적어 둡니다.

쓰다가 막힌 자리에서 고친다

기능을 미리 설계해서 넣기보다, 직접 쓰다가 막힌 자리를 하나씩 메웁니다. 그래서 변화 이력의 대부분이 "쓰다 보니 필요해서"입니다.

02

이 사이트는 이렇게 만들었습니다

직접 만든 정적 사이트입니다. 프레임워크도, 빌드 과정도, 추적 스크립트도 없습니다.

  • HTML · CSS · JavaScript 뿐

    React 같은 프레임워크를 쓰지 않았습니다. CSS 한 개, JS 몇 개, 이미지 없음. 마크다운 변환기도 외부 라이브러리 없이 직접 짧게 만들었습니다.

  • JS 없이도 읽힙니다

    본문은 HTML 과 마크다운에 그대로 있고, 자바스크립트는 필터·발표 모드·목록 그리기만 합니다.

  • 색을 지어내지 않았습니다

    브랜드 색이 없으므로 무채색으로 만들었습니다. Slides-in-Html 스킬이 정해 둔 규칙("브랜드 색을 모르면 무채색")을 사이트에도 그대로 적용한 것입니다. 프로젝트 페이지 맨 아래에서 이 페이지 자신의 명도 대비를 실제로 계산해 보여 줍니다.

  • 글은 사이트 안에서 씁니다

    관리자 화면에서 글과 프로젝트를 쓰면 저장소에 바로 저장됩니다. 서버가 없으므로 로그인은 내 GitHub 토큰으로 대신합니다 — 그 토큰은 제 브라우저에만 있습니다.

무엇을 참고했고 무엇을 버렸는지는 DESIGN.md 에 전부 적어 뒀습니다.
