들어가기

이 사이트에는 서버가 없습니다. 그래서 로그인 대신 내 GitHub 토큰으로 저장소에 직접 씁니다. 토큰은 이 브라우저에만 저장되고 어디로도 전송되지 않습니다(GitHub 외).

예: hyukjae/my-site
GitHub → Settings → Developer settings → Fine-grained tokens → 이 저장소 하나만 고르고 Contents: Read and write 권한만 주세요.
알아 두실 것 토큰은 이 브라우저의 저장 공간에 그대로 들어 있습니다. 공용 컴퓨터에서는 쓰지 마세요. 권한을 이 저장소 하나로 좁혀 두면, 혹시 새더라도 피해가 이 사이트 안에서 끝납니다. 다 쓰고 나서 토큰 지우기를 누르면 브라우저에서 지워집니다.

이 브라우저에만 있는 글입니다. 저장소에 올라가지 않으므로 사이트에서는 보이지 않습니다. 브라우저 저장 공간을 비우면 함께 사라지니, 오래 둘 글은 .md 로 내려받아 보관하세요.

아직 비공개 글이 없습니다. "새 글"에서 비공개를 고르고 저장하면 여기에 쌓입니다.

스킬 파일(.skill)이나 설명서(.md)처럼 글이 아닌 파일을 저장소에 그대로 올립니다. 글·프로젝트 목록에는 나타나지 않고 파일만 놓입니다.

저장소 뿌리부터의 경로입니다. 기존 스킬 파일들이 docs/ 에 있습니다.

아직 고른 파일이 없습니다.

파일 하나에 1MB 까지 이 방식은 파일이 1MB 를 넘으면 쓸 수 없습니다. 더 큰 파일은 GitHub 웹에서 Add file → Upload files 로 올리세요. 참고로 docs/slides-in-html.skill 은 약 88KB 입니다.

저장소에 지금 올라가 있는 글과 프로젝트입니다. 사이트가 아니라 저장소를 직접 읽으므로 방금 올린 것도 바로 보입니다. 내리면 목록에서 빠지고 본문 파일이 지워집니다. 사이트에서는 사라지지만 GitHub 기록에는 남아 나중에 되살릴 수 있습니다.

저장소에 올라가 있는 글이나 프로젝트가 없습니다.

직접 만든 페이지를 쓰는 프로젝트 목록에 page 가 적힌 프로젝트(예: 직접 쓴 HTML 페이지)는 목록에서만 빠집니다. projects/ 안의 그 HTML 파일은 남아 있습니다. 주소를 아는 사람은 계속 열 수 있으니, 정말 없애려면 저장소에서 그 파일도 지우세요.

저장하면 무슨 일이 일어나나

① 본문을 content/posts/<이름>.md 로 커밋하고 ② data/posts.json 목록에 한 줄을 더한 뒤 커밋합니다. GitHub Pages 가 다시 배포하는 데 보통 1~2분 걸립니다.

같은 이름으로 다시 저장하면

덮어씁니다. 글을 고칠 때는 같은 이름으로 저장하면 됩니다. 목록의 제목·요약·꼬리표도 함께 갱신됩니다.

지우려면

올린 것 관리 탭에서 내리기를 누르면 됩니다. data/ 의 json 에서 그 줄을 빼고 content/ 의 .md 파일을 지웁니다. 커밋 두 번으로 끝납니다. 지운 뒤에도 GitHub 기록에는 남아 있어 되살릴 수 있습니다.

스킬 파일·설명서를 올리려면

파일 올리기 탭에서 폴더(기본 docs)를 정하고 파일을 고르면 그대로 저장소에 올라갑니다. 같은 이름이 있으면 덮어쓸지 물어봅니다. 글·프로젝트 목록에는 나타나지 않으니, 사이트에서 보이게 하려면 프로젝트 본문에 [설명서](../docs/파일이름.md) 처럼 링크를 거세요.

수정 제안 스프레드시트

프로젝트 페이지의 제안 폼은 assets/js/config.js 의 suggestEndpoint 로 보냅니다. 만드는 방법은 저장소의 google-apps-script.gs 맨 위에 적어 뒀습니다.
