들어가기

이 사이트에는 서버가 없습니다. 그래서 로그인 대신 내 GitHub 토큰으로 저장소에 직접 씁니다. 토큰은 이 브라우저에만 저장되고 어디로도 전송되지 않습니다(GitHub 외).

예: hyukjae/my-site
GitHub → Settings → Developer settings → Fine-grained tokens → 이 저장소 하나만 고르고 Contents: Read and write 권한만 주세요.
알아 두실 것 토큰은 이 브라우저의 저장 공간에 그대로 들어 있습니다. 공용 컴퓨터에서는 쓰지 마세요. 권한을 이 저장소 하나로 좁혀 두면, 혹시 새더라도 피해가 이 사이트 안에서 끝납니다. 다 쓰고 나서 토큰 지우기를 누르면 브라우저에서 지워집니다.
